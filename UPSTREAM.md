# Upstream and licensing

This repository is an Adverserial AI confidential-inference fork of
[Open WebUI](https://github.com/open-webui/open-webui), based on upstream
Open WebUI `v0.11.3` plus Adverserial's confidential-verification changes.

The complete upstream [Open WebUI License](./LICENSE) is retained. This fork
must be deployed in accordance with its branding and other license conditions.

Adverserial-specific confidential components are documented in
[`docs/CONFIDENTIAL_INFERENCE_ARCHITECTURE.md`](./docs/CONFIDENTIAL_INFERENCE_ARCHITECTURE.md).

Please report security vulnerabilities directly to
[security@adverserial.ai](mailto:security@adverserial.ai). Do not open a public
issue for a suspected vulnerability.
